## Repo Guidance for Autobuild

- **Stack:** Static HTML/CSS/JS site served by GitHub Pages. No build step, no package manager, no test framework.
- **Default branch:** `gh-pages` (the live site branch).
- **Map library:** Mapbox.js v2.0.1 loaded via CDN (`api.tiles.mapbox.com/mapbox.js/v2.0.1`). Mapbox access token is hardcoded in `art.js`.
- **Data:** Art pieces stored as GeoJSON features in `art.geojson`. Each feature has properties: `url` (full image path), `image` (thumbnail path), `nav` (nav thumbnail path), `pieceID` (integer), `picnote` (text description), `icon` (icon config object), `marker-color`, `marker-size`.
- **Content scripts:** `add_image.py` and `replace_image.py` are Python 2 scripts using PIL/Pillow. They resize images into multiple sizes and update GeoJSON. Run manually, not part of a CI pipeline.
- **Images:** Generated by the Python scripts into `images/`. Naming convention: `{pieceID}.jpg` (full), `{pieceID}_thumb.jpg` (thumbnail), `{pieceID}_icon.png` (map icon), `{pieceID}_nav.jpg` (nav thumbnail).
- **Lazy loading:** `lazysizes.min.js` for lazy-loading nav thumbnails.
- **Custom domain:** `atlantaartmap.com` via `CNAME` file.
- **No lint, typecheck, or test commands** — this is a static site with no tooling.
